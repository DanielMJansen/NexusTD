# Nexus — protótipo v1

## Rodar local
Precisa do Node.js 20+.
    npm install
    npm run dev      # abre em http://localhost:5173 (no celular: use o endereço "Network" na mesma rede Wi-Fi)

## Publicar no GitHub Pages (grátis, online 24h)
1. Crie um repositório no GitHub e envie esta pasta (branch `main`).
2. Em Settings → Pages, escolha **Source: GitHub Actions**.
3. A cada `git push`, o jogo é publicado em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
